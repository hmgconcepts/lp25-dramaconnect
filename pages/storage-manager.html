Archive Vault — move old rows into the 1 GB file storage

Deletes and file storage are separate: the database frees up only when rows are deleted. This does it safely — the old rows are exported to a JSON file, uploaded to the private dramaconnect-backups bucket, verified against its SHA-256 and the live row count, and only then deleted. Everything stays restorable.
